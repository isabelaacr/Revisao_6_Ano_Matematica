📓 Revisão de Matemática — Frações, Porcentagem e Grandezas

Site de estudo interativo, com visual de caderno espiral, desenvolvido para revisar conteúdos de Matemática do 6º ano: frações, porcentagem, razão e proporção e grandezas.

Além do site, o repositório inclui um material de apoio em Word (.docx), preparado para impressão e estudo offline.

O projeto foi desenvolvido com HTML, CSS e JavaScript puros, sem frameworks, dependências ou etapa de build. Basta abrir o arquivo HTML no navegador.

📂 Arquivos
Arquivo	Descrição
revisao-matematica.html	Site interativo completo. Pode ser aberto diretamente no navegador.
material-apoio-fracoes-porcentagem.docx	Material de apoio para impressão, com definições, exemplos resolvidos, exercícios e gabarito.
🚀 Como usar

Não é necessário instalar nada nem configurar um servidor.

Basta abrir o arquivo revisao-matematica.html em um navegador como Chrome, Firefox, Safari ou Edge, tanto no computador quanto no celular.

Opcional: executar com servidor local
python3 -m http.server 8000


Depois, acesse:

http://localhost:8000/revisao-matematica.html

🧭 Abas do site
📗 Frações & Porcentagem
Conversor de fração para porcentagem.
Quadriculado de 100 casas interativo.
Representação de porcentagens usando poltronas de cinema clicáveis.
Cálculo mental de porcentagens.
🍕 Tipos, Simplificar & Dividir
Classificação de frações:
própria;
imprópria;
aparente.
Representação visual das frações com pizzas.
Simplificação passo a passo, utilizando botões de divisão.
Divisão de frações pelo método “guarda, troca, inverte”.
📝 Resolva sua Lista

Seis ferramentas genéricas para resolver exercícios semelhantes aos encontrados em listas escolares:

Operações com frações.
Fração ou porcentagem de um total.
Razão entre quantidades.
Velocidade, vazão, densidade e escala com valor desconhecido.
Porcentagem em três formatos diferentes.
Conversor entre fração, porcentagem e decimal.

Todas as ferramentas apresentam o cálculo passo a passo, ajudando o aluno a entender o processo e não apenas encontrar o resultado.

🧮 Desconto & Acréscimo

Calculadora interativa para trabalhar com:

descontos;
acréscimos;
valores iniciais e finais;
representação visual proporcional.
⚖️ Razão & Proporção

Resolvedor de proporções utilizando multiplicação cruzada, com blocos visuais para facilitar a comparação entre as grandezas.

🚗 Grandezas

Ferramentas interativas para estudar:

🚗 velocidade, com carrinho animado;
📊 densidade demográfica, com velocímetro;
💧 vazão, com tanque enchendo;
📏 escala, com régua ilustrativa.
✅ Quiz Final

Quiz com 6 questões mistas, sistema de pontuação e explicações.

Quando o aluno erra uma questão, o sistema mostra uma explicação indicando por que a resposta está incorreta e como chegar ao resultado correto.
